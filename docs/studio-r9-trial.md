# R9 试用与演示

## 准备一次即可

按 README 安装并启动，打开本机地址。在项目菜单选择“导入项目 JSON”，导入 examples/studio-r9/beginner.json 或 advanced.json。每轮试用重新导入以保留前一轮记录。导入前保存当前草稿。只使用合成项目，参与者可随时停止。

## 初学者项目

需求为非空列表返回第一项，空列表返回0，main.py最终输出1。

1. 打开 helper.py，自动定位缺少冒号，展开本地详细解释并查看提示。
2. 补上冒号，保存，观察语法复查事件。
3. 打开 main.py，验证当前入口，看到 None 与整数相加的错误及执行轨迹。
4. 在 helper.py 函数末尾补上四空格缩进的 return 0，保存。
5. 打开 main.py 再验证，输出1。将 main.py输入换为[7]，输出8以核对非空行为。
6. 在存储与备份中导出匿名试用记录，并导出项目JSON作为恢复备份。

## 进阶者项目

需求为报价取首项，空输入报价0，main.py加2后输出2。main.py通过别名estimate调用pricing.quote，后者调用numbers_local.first。

1. 阅读三个文件，预测当前执行的返回值与异常位置。
2. 验证main.py，记录异常。展开轨迹，跟踪跨文件参数和返回值。
3. 授权的实时模型可分析调用链、引用源码并提出建议。确认建议的适用条件后审批Diff，或手动修改numbers_local.py，在末尾增加return 0。
4. 保存后重新验证，输出2。换为[9]应输出11。
5. 若采用Diff，立即撤回应恢复前一草稿；若随后手动编辑，撤回应提示冲突并保护编辑结果。
6. 导出匿名记录与项目备份。相对导入属于独立模型评测场景，当前受限执行器对它显示不支持。

## 演示模式

默认本地模式提供自动语法诊断、确定性教学、受限执行、项目保存和学习事件。需要外部模型生成的深层讲解与工具调用时，使用经授权配置的实时模式，并明确展示模型状态。模型服务失败时仍可编辑和运行本地检查。

历史回放仅证明保存结果的显示，必须标注来源、时间与代码版本。R8已有回放截图不代表R9实时成功。离线模式不能展示为实时模型分析。

## 匿名反馈模板

由真实参与者或现场观察员填写，每位参与者使用随机试用编号，不记录姓名、学号、联系方式。

- 试用编号、项目（初学者/进阶者）、版本提交号、模式（本地/实时/回放）
- 事先预测的输出或错误
- 首次理解错误原因的步骤、仍不清楚的解释原文
- 是否查看提示、尝试了哪些修改、最终执行结果
- 有无错误建议或编辑被覆盖，附最小合成复现
- 操作困难与建议
- 是否同意团队保留这份匿名反馈及必要事件记录

日志仅含最近最多200条去重后的事件类型、代码哈希、修订号与证据来源。相同代码重复事件可能合并，未保存的每次击键不采集。这些记录不能直接推导独立掌握或学习提升比例。
