
# AI Web 提交检查清单

## 队长与资格

- [ ] 向组委会确认旧作品复用许可并保存书面回复，确认团队成员、参赛组别、缴费及评审入口。
- [ ] 以 2026-11-18 为截止，查个人中心确认具体时刻和提交批次。17 日完成内审并争取提交。
- [ ] 写明团队分工、原项目来源、旧能力与本届新增。参赛人逐项核验归属和第三方素材许可。

## 仓库与复现

- [ ] 用已批准的 GitHub 或 Gitee 仓库保留真实提交历史，验证评审访问权限。提交前做包含全历史和打包内容的凭证与隐私扫描。
- [ ] 核对没有 .env、密钥、真实数据库、真实学生代码、node_modules 或旧压缩包。疑似曾外传的密钥由持有人确认和轮换。
- [ ] 记录提交版本和运行环境。另一台电脑完成 Python/Node 依赖安装、构建和启动。
- [ ] 现场演示至少复现循环边界和一条证据不足，验证提示后通过与独立通过推荐不同。
- [ ] 完成真实模型授权、预算、调用测试和结果披露。确认报告内模式与评测结果一致。

## 交付材料

- [ ] 技术报告 PDF ≤30 页，含概述、需求、架构、AI 方案、核心实现、创新、测试、部署、局限与展望。
- [ ] 演示成片为普通话 MP4、5–8 分钟且至少 1080p，导出后全片回看。视频、PDF 与仓库引用同一版本。
- [ ] 公网演示若纳入，先完成上线审批、HTTPS、鉴权隔离、限流、用量和故障演练，再提供评审地址及必要的专用账号。
- [ ] 通过赛事个人中心提交，核对上传成功和评审可访问，保存回执。

规则来源：[AI Web 赛项页](https://m.saikr.com/vse/2026AIWEBKF)。
