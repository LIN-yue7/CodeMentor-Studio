# CodeMentor AI 2.0 工作台重设计
日期：2026-11-09。用户授权自行选择设计方向并实施；保留后端接口。

## 三种方向与决策
1. 深色实验工作台：实验导航 / 主代码与复测 / 证据侧栏。信息并置、减少往返，代价是深色系统需要仔细校准对比度。采用。
2. 浅色教学手稿：纵向代码与批注；阅读亲和，但长解释拉长操作路径。
3. 双屏对照实验室：代码与反例等宽；适合演示，但压缩编辑区域。
参考公开产品理念：[Cursor](https://cursor.com/features) 的代码上下文、[Linear](https://linear.app/features) 的紧凑工作流、[Geist](https://vercel.com/geist/introduction) 的统一组件与对比度。仅参考原则，不复刻界面。

## 信息架构
桌面 1440px：194px 实验目录、可伸缩主工作区、390px 证据侧栏。主工作区上方编辑器，下方变式复测；侧栏上方诊断、下方学习记录。
移动端：实验选择 → 编辑 → 证据 → 复测 → 记录。固定顶部快捷导航，保留所有内容，不隐藏关键业务。
编辑器和反例保持空间关联；点击证据行号聚焦代码。改动后突出旧证据提示，禁止用旧行号跳转。
诊断状态、提示计数、评分、不同题独立通过数来自既有 API。不制造 AI 运行步骤。未配置模型明确本地模式。

## 设计系统
字体：系统无衬线（Segoe UI / Microsoft YaHei）；代码 Cascadia Code / Consolas。无需外部字体请求。
层级：品牌 17px；区域标题 14px；正文 13px / 1.65；编辑器 14px / 1.85；辅助 11–12px。
颜色：底色 #101315、面板 #171b1e、编辑器 #121619、边线 #2b3237、正文 #e3e9e6、次级 #98a6a1。
强调 #9bdfbd；证据 #e5bb7b；失败 #f1a9a0。成功/警告都配文字，不仅依赖颜色。
间距：4/8/12/16/24/32px。容器以分隔线为主；交互控件 6px 圆角；不使用渐变与卡片阴影。
交互：hover / focus-visible / disabled / pending / cancelled / failed / stale / success；键盘焦点清晰；按钮至少 36px，手机至少 44px。
动效：颜色/边框 120ms；无虚构进度动画；尊重 prefers-reduced-motion。
内容：逐级展开课程来源与真实执行步骤；提示用真实次数累计；反馈明确独立或辅助通过。
手机输入字号 16px 防缩放；代码内部滚动和自动折行，不产生页面横向滚动。
