- 模型输出仍有正确代码上的过度建议倾向，跨文件样本失败尚未解决。
- 没有自主Agent、真实Function Calling、经过评测的项目RAG、多模态、可审阅补丁或项目代码执行沙箱。
- 项目学习记录仅本次会话；旧教学实验的学习数据不等于新项目长期画像。

- 材料是阶段稿；正式MP4未录制，资格/复用来源/提交时刻未核完。
