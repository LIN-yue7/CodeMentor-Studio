# CodeMentor Studio R7 实施与验收记录

验收日期：2026-11-13；真实模型测试于2026-11-12完成。产品代码 9f53dcd；分支 studio-r7，继承 R6 876ac18；原交接目录未修改。此文是阶段验收，不代表全部国赛能力或最终提交完成。

## 本轮实际实现

- 左侧 220px 项目导航：项目名称菜单、弹窗创建/切换/JSON 导入/设置；常驻项目创建表单已移除。无项目时提供四个可操作入口；恢复最近项目与最近文件。
- 文件树搜索、层级折叠、当前文件、未保存与问题数标记；右键创建/重命名/删除文件，文件夹子树重命名/删除。目录通过文件路径创建，不单独持久化空目录。
- 多文件标签；Python/纯文本/自动语言模式，切换使用 CodeMirror Compartment 保留光标选择。其他语言目前仅文本编辑，不宣称完整多语言 IDE。
- 右侧统一“实时代码反馈”，展示位置、为什么出错、怎样修改；详细信息展开。自然语言深度操作不引入全局模式。
- 建议补丁逐字校验源行，显示前后 Diff，用户批准后才写入草稿；代码变化后作废。审批不等于逻辑正确，仍需验证。
- 项目上下文增加导入关系、符号定义与文档词项的有界排序检索，包含候选理由、行号和原文。支持相对导入的静态检索、后部定义及有语法错误时的有效 import 恢复。不是向量检索，也没有大规模召回评估。
- 学习事件持久化到所有者隔离的表：解析器发现、保存版本间语法复查、主动查看易错点、受限执行结果。去重，不把查看次数写成掌握程度；尚非成熟的自适应长期画像。
- 受限 Python 子集解释器实际执行项目内导入、简单函数、if、return、列表索引、数值加减和 print。禁止宿主文件/网络访问与任意执行，限制步骤、深度、值与输出；超出支持范围明确返回 unsupported。不是完整 CPython 沙箱。

## 实际教学闭环

点击“体验示例”，打开 main.py 与 helper.py；main 调用 helper.first([])+1。先在 helper 去掉冒号观察本地定位、解释与自动复查。恢复冒号后运行当前入口，None + 1 产生运行错误；将 helper 的 return None 改为 return 0，再运行 main，实际输出 1，并写入学习记录。

四视口均执行这个闭环，证据在 evidence/studio-r7/round-3/*-execution.json。模型对错误版的真实解释及 Diff 在 live-02-retrieval.json；修复版真实浏览器调用与截图在 live-04-*。这是分次真实测试证据，不伪装为一次连续现场模型调用；UI 自动回归中的模型路由模拟另有明确 simulated 标签。

## 尚未完成与明确限制

1. 没有自主 Agent 选工具、真实 Function Calling/MCP 调用或多模态；确定性流程和普通 API 不计作这些能力。
2. 项目检索已接到模型上下文，但尚无独立标注召回集、消融实验；学习记录已持久化，但未实现充分验证的个性化解释策略。
3. 未提供完整 Python 运行环境、任意包安装、调试器、完整多语言语义检查或多种诊断严重度。受限解释器仅验证支持的语法与输入。
4. 暂无流式输出、跨浏览器账号。匿名身份7天，未设置固定会话密钥时重启不能自动恢复归属；JSON导入导出可用。
5. 文件标签切换会重建编辑器，未保留每个文件的撤销历史和光标位置。目录由文件路径推导，空目录不持久化。弹窗完整键盘焦点圈定、触屏文件右键替代入口还需打磨。
6. 没有真实学习者试用、教学效果与商业付费意愿证据。未正式发布公网/托管仓库，未生成5–8分钟正式MP4，技术报告仍为阶段稿。

这些缺口使本版本不能称为用户全部R7要求已完成或国赛最终成品。已交付可运行的核心增量与真实证据，下一阶段优先完善长期编辑状态和触屏操作，再接真实受控工具选择与检索评测。
