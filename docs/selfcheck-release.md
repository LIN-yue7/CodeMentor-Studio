# R3 概念自查交付记录（2026-11-10）

## 本轮实现

诊断 → 展开“用一道自查核对理解” → 选择答案 → 确定性反馈 → 下一次诊断参考最近一次自查。

三道审核题覆盖 range 上界、空列表与零元素的区别、跨轮次累加。首次提交前接口不返回答案；按身份隔离，每次诊断保留首次答案，相同答案重复提交返回相同结果，不同答案返回 409。未知代码不提供自查。记录写入现有诊断 JSON，不修改旧表结构、不执行用户代码。

自查标注为讲解后行为，不计入独立掌握；个人错因始终 unconfirmed。建议由确定性策略生成，不冒充 LLM 决策。新后端声明自查能力，旧后端未声明时前端隐藏入口。

源码：app/services/workbench_selfcheck.py、workbench-web/src/SelfCheck.tsx；测试：tests/test_workbench_selfcheck.py、workbench-web/e2e/selfcheck.spec.ts。

## 未完成及限制

只有三道固定自查题，重复作答可能依赖记忆，不能证明迁移学习或个人认知错因。自查尚无统一历史、导出或删除入口；自述删除不会删除自查记录。历史仍扫描诊断 JSON，需改善索引与分页。
匿名身份仍无恢复机制；同一主机不同端口的默认 Cookie 同名，切换实例可能产生会话冲突。正式使用应固定单个实例；账号恢复和实例隔离是下一优先事项。
真实模型对照、用户验证、完整规则核对、官方评分证据矩阵及正式报告/视频仍待完成。本轮不是整个比赛项目完成。
源码包不含 .env、用户数据库、本地虚拟环境或未集成的 causal_lab 草稿。
