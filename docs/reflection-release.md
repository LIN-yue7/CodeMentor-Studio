# R2：详细诊断与学习自述（2026-11-09）

## 实际实现

- 诊断包含技术原因、修改路径、自查问题、下一步行动、依据与不确定性。
- 三个审核场景：循环边界、空列表、累加状态。未匹配代码不强行归因。
- 学习者可自述敲错/漏写、概念、思路、题意或尚不确定，并记录最多 600 字的思考与提醒。
- 自述存入现有诊断 JSON，按身份隔离，可修改与删除；重复保存更新同一条记录。无需数据库结构迁移。
- 下一轮相同知识点的建议参考最近自述；历史按原因计数。不把自述当成证实的能力判断。
- 桌面诊断详情独立滚动并支持键盘焦点；移动端保持自然阅读顺序。

## 关键代码

- app/services/workbench_reflection.py：审核指导、历史统计、记录更新。
- app/api/workbench.py、app/schemas/workbench.py：受身份保护的接口及输入校验。
- workbench-web/src/ReflectionPanel.tsx：详细指导、记录、纠正、删除。
- tests/test_workbench_reflection.py、workbench-web/e2e/reflection.spec.ts：隔离与闭环验证。

## 独立评审步骤

按 docs/workbench.md 安装和启动，新工作台默认地址 http://127.0.0.1:8765/ 。本地 CODEMENTOR_AI_MODE=local，不需要模型密钥。

1. 提交循环边界例子，查看反例、为什么出错、修改建议和自查问题。
2. 展开“记录我的原因与思路”，选择“概念记得不牢”，写下自己的想法，保存。
3. 再次诊断同类代码，应显示“你上次自述概念不稳”及对应建议。
4. 查看学习记忆，纠正记录，再删除；新一轮诊断不应继续引用已删除自述。
5. 换独立浏览器身份，不应看到别人的自述。
6. 输入不在审核模式中的代码，应保留不确定性，不应给出确定的个人归因。

## 尚未达到的能力与风险

- 本轮没有真实 LLM 推理测试；详细指导是审核内容加确定性策略，不是模型自动读懂心理原因。
- 尚未通过追问、自由解释评分与迁移测试自动确认个人错因；没有真实教学效果实验。
- 记忆限学习自述及已有作答记录，不采集无关个人信息。当前为浏览器会话身份；默认服务密钥重启变化、清除身份或更换浏览器可能使旧记录无法访问，尚不是持久账号体系。
- 删除自述会阻止后续新诊断使用它，但已经生成的诊断建议和计数是历史快照，不会追溯改写。本功能不是全面的数据清除接口。
- 当前记忆读取尚未分页，需在积累大量记录前完善容量与性能测试。
- 原型因果实验与候选方向研究未并入本次发布，不作为本次已实现能力宣传。

下一优先级：可恢复的用户身份与完整记忆管理；“解释规则—选择反例—独立变式”的归因验证协议；经授权后真实模型结构化归因及对照评估。
