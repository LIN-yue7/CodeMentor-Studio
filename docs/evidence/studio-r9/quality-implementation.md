## 补丁检查

把同一批补丁按编辑器的逐行替换规则应用到内存副本，检查变更后的 Python 语法。复用受限 AST 解释器比较当前入口的前后运行状态和实际输出。出现新运行错误、候选语法错误或与受限求和参考样例矛盾时，隐藏整组应用操作。输出变更、原有错误仍在或错误消失时明确提示复核。解释器不支持、没有可比较输出或缺少受影响文件执行迹象时，结果保持未知。候选仍需用户批准，`claim_status` 一直为 `unverified`。补丁检查不会应用、保存代码或写入用户运行记录。

求和取样仅支持受限解释器内的数值列表。对历史补丁中「赋一个常量后直接返回同一局部变量」的直线片段，先在 AST 上消去该局部赋值再取样。解释器仍拒绝一般函数内重新绑定、循环、相对导入执行、复杂参数、宿主导入和 IO。对相对导入的本轮改动覆盖静态检索和工具读取。

- `get_current_file` 保留现有默认入口，新增授权虚拟项目内的精确相对路径读取。拒绝越界、不存在及非法路径。仍为 6 个只读工具、3 轮、6 次调用，每个工具结果不超过 8,000 个字符。
