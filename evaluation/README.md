
# AI 技术验证记录

## 固定数据和对照口径

`cases.json` 是 24 条合成用例及预期标注。12 条覆盖三种已知错因及等价变量名、注释、缩进变化，另有 7 条正常或意图不匹配、3 条语法异常、1 条已知但规则未覆盖的错误、1 条不可信代码。样本由实现规则和负例构造，适合作为回归集，不能外推到任意 Python 程序。

- A 为旧 TutorAgent 诊断，采用旧提示词和结构化输出。离线没有真模型时记作未运行。旧返回结构没有专用行号和引用字段，按不可结构化核验记录。历史初始化为空，避免比较时输入条件混杂。
- B 为证据校验和练习闭环，关闭课程检索。C 同一编排接入检索。离线 B/C 都运行本地路径。真模型比较使用同一服务、模型和温度，按同样的固定集运行。
- 缺字段、伪造引用、错误行号和超时由模拟模型测试覆盖。模拟结果仅用于契约验证。B/C 证据匹配相同由架构决定。引用 ID 有效和引用语义恰当是两项不同检查，后者需盲审模型解释。

## 离线结果

| 指标 | A | B | C |
|---|---:|---:|---:|
| 已覆盖错误错因命中 | 待真实模型 | 12/12 | 12/12 |
| 有可比定位的行号命中 | 结构无独立行号 | 14/14 | 14/14 |
| 正常或意图不匹配样本的错误误记 | 待真实模型 | 0/7 | 0/7 |
| 在可检索样本中命中人工指定课程卡 | 无课程卡 | 0/12 | 12/12 |
| 证据不足返回 | 待真实模型 | 9 | 9 |

24 条用例逐条结果见 `offline-results.json`，包含本地编排耗时。亚毫秒计时仅反映当前机器上的本地逻辑，未含浏览器、网络和模型。B/C 输出未覆盖的 `sum(xs[1:])` 为不确定，表明保守规则会漏检陌生形式。无任务契约的循环样例也保持不确定。

## 变式质量和学习状态

九个版本化模板含题干、判分答案、两个提示和解释。用题意分别推导答案，循环边界三题为 6、7、11，空列表三题为 -1、0、8，累加状态三题为 7、5、0。浏览器实际复测首两道循环题。提示后通过、独立通过、未通过及同题重复操作分别处理。模板数量和结构完整性来自程序检查，暂无外部教师盲评或学生学习增益数据。

真模型实验拟同时记录每条输出、引用 ID 命中与人工证据一致性、格式失效率、错误记入、练习可用性及端到端延迟。真实教学成效需另行设计对照教学试验。
